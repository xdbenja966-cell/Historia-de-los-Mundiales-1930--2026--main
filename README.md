Organización del trabajo

Para realizar este proyecto decidimos dividir las tareas de manera equitativa entre los tres
integrantes del grupo. Antes de comenzar, analizamos el diseño y la estructura de la página
correspondiente al Mundial de Uruguay 1930, la cual fue desarrollada primero y utilizada
como modelo base para la creación del resto de los mundiales del sitio web.

La idea principal fue crear una estructura uniforme para todas las páginas, manteniendo el
mismo estilo visual, organización de la información y diseño general, modificando
únicamente los datos históricos correspondientes a cada edición del Mundial.

Metodología utilizada
El trabajo comenzó con el desarrollo completo de la página correspondiente al Mundial de
Uruguay 1930. Esta página fue utilizada como base para el resto del proyecto debido a que
ya contaba con:

● Estructura HTML organizada.
● Diseño CSS funcional.
● Sistema de navegación.
● Tablas y secciones informativas.
● Formato visual uniforme.

Una vez finalizada la página de 1930, se tomó como plantilla para construir las demás páginas de los distintos mundiales. De esta manera se evitó repetir código
innecesariamente y se logró mantener una apariencia consistente en todo el sitio web.

Cada integrante realizó su parte de forma individual y posteriormente se efectuaron
reuniones grupales para integrar el trabajo, corregir errores y verificar el correcto
funcionamiento de todas las páginas.
Conclusión.

La división de tareas permitió trabajar de manera organizada y eficiente. El uso de la página
del Mundial de 1930 como modelo base facilitó la creación de las demás secciones del
proyecto, reduciendo tiempos de desarrollo y manteniendo una estructura uniforme en todo
el sitio web. 
Gracias al trabajo colaborativo de los tres integrantes se logró completar
correctamente el proyecto de la Historia de los Mundiales.
